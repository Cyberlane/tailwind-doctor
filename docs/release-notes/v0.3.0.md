# Tailwind Doctor v0.3.0

This release adds first-party Neovim diagnostics while preserving Tailwind
Doctor's local, deterministic, static-analysis boundary.

## Highlights

- Neovim 0.11 and newer can enable the native `tailwind_doctor` LSP
  configuration directly from this repository.
- The configuration launches `tw-doctor lsp`, supports the same source
  filetypes as the VS Code extension, selects project roots from
  `twdoctor.toml`, `package.json`, or Git, and debounces changes by 120 ms.
- Installation documentation covers lazy.nvim, Neovim's native package
  mechanism, custom CLI paths, health checks, and project-context reloads.
- CI launches the real language server in Neovim 0.11.5, opens a temporary
  Tailwind buffer, and verifies that a diagnostic reaches the editor.

## Compatibility

The Neovim integration requires Neovim 0.11 or newer and a separately installed
`tw-doctor` CLI. Existing CLI, JSON, SARIF, baseline, scoring, and rule contracts
are unchanged.

All analysis remains local. Neither the CLI nor either editor integration
executes application code, writes source files during analysis, or makes network
requests.

# Tailwind Doctor v0.4.0

This release redesigns the human report around how doctor-style tools are
actually read, and fixes a package-scoping bug that silently disabled the
theme for monorepo apps scanned on their own.

## Your score may change

Two fixes in this release remove false findings and extend theme coverage, so
a project's score can move — usually upward:

- A v4 CSS entry with no `package.json` inside the scanned directory now
  scopes its package to the scan root. Projects hit by the old behaviour gain
  theme-aware analysis for every file: token usage, exact-match suggestions,
  contrast trust, and high-confidence conflict classification.
- Utility classification now consults Tailwind's default theme when no project
  theme resolved, and separates border sides and kinds. False conflicts such
  as `text-4xl` vs `text-gray-600`, `border-y` vs `border-r`, and `border-l`
  vs `border-l-transparent` no longer occur, and a conflict found only through
  a shared lexical prefix stays medium confidence and score-neutral.

A token split by a template-literal substitution, such as `text-[${size}px]`,
is now recorded whole as one unresolved site instead of linting invented
fragments like `text-[`.

## The report reads like a checkup

- Coverage renders as check lines with judgments (`✓`, `✗`, `•`) instead of
  bare counts, and internal accessibility reason codes moved to `--json`.
- A per-rule summary and a repeated-arbitrary-values block say what kind of
  debt dominates before the list says where it is; one value used 165 times
  reads as one missing token, not 165 problems.
- Findings group under one header per file and truncate at a file boundary
  after 100; `--json` and `--sarif` stay exhaustive.
- Unscored findings are summarized as a count rather than interleaved with
  scored ones.
- The report says how many findings `--fix` would resolve, and ends with a
  one-line verdict that repeats the score and names the `--fail-under` gate
  and whether it passes.
- Output uses ANSI color when writing to a terminal. Color only wraps text —
  stripping the escapes yields the plain report byte for byte — and pipes,
  redirects, `NO_COLOR`, and `TERM=dumb` always get plain text.
- Counts are grammatically pluralized, arbitrary-value messages name the
  offending class, and the report warns when most resolved class lists fall
  outside every detected Tailwind package.

## Compatibility

JSON schema, SARIF output, baseline format, exit codes, rule IDs, and
configuration are unchanged. The human report format changed substantially;
it has never been parseable-by-contract, and anything scripted should read
`--json` or `--sarif`.

All analysis remains local. The CLI executes no application code, writes no
source files during analysis, and makes no network requests.

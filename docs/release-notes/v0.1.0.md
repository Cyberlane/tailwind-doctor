# Tailwind Doctor v0.1.0

Tailwind Doctor's first public release measures design-system debt in Tailwind
class lists without executing a project's code or sending its source anywhere.

Highlights:

- deterministic human, JSON, and SARIF reports;
- a documented, size-normalized Design System Health Score;
- structural extraction across HTML, JSX/TSX, Vue, Svelte, Astro, class helper
  calls, template literals, and CSS `@apply`;
- static Tailwind CSS v3/v4 token inventories and exact replacement suggestions;
- conservative WCAG 2.2 colour-contrast evidence with explicit coverage gaps;
- opt-in `--fix` for arbitrary values proven to match a named token exactly;
- prebuilt npm binaries for macOS arm64/x64, Linux arm64/x64, and Windows x64.

`unused-token` and `color-contrast` are fully implemented but disabled by
default for this introductory minor release. Enable either rule explicitly in
`twdoctor.toml` while evaluating it against an existing project.

Install or run:

```bash
npx tw-doctor .
npx tailwind-doctor .
```

Every attached archive is covered by `SHA256SUMS` and GitHub build provenance.

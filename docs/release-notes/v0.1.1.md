# Tailwind Doctor v0.1.1

This patch release tightens Tailwind Doctor's high-confidence boundary.

- Stacked variants retain source order, avoiding false conflicts for
  order-sensitive selectors.
- A configured Tailwind prefix excludes unprefixed application classes from
  findings, token usage, and score exposure.
- Module-level `cn`, `clsx`, `classnames`, and `cva` calls require import
  evidence; imported aliases remain supported, and contextual calls inside
  class-bearing expressions continue to work.
- Release recovery and path handling are deterministic, and release notes are
  selected from the signed tag.

There are no new rules or scoring-model changes. Scores may rise where a prior
build reported one of the corrected false positives.

Every attached archive is covered by `SHA256SUMS` and GitHub build provenance.
